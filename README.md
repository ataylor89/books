# books

I'll choose books from all genres - poetry, drama, fiction, nonfiction.

Some of my choices will be textbooks, because that falls under the category of nonfiction.

This list is not comprehensive.

It includes some of my favorite books, but not all of my favorite books.

I plan to add more over time.
